
# Address Book Management System in C

A menu-driven Address Book application developed using C programming. This project demonstrates fundamental C concepts, including structures, functions, pointers, string handling, and file operations.

## Features

- Add new contacts
- Search for contacts
- Edit contact details
- Delete contacts
- Display the contact list
- Store and retrieve contact information using file handling
- Menu-driven command-line interface

## Technologies Used

- C Programming
- GCC Compiler
- Linux / Ubuntu
- Standard C Library

## Project Structure

```text
Address-Book-Using-C-Programming/
├── main.c
├── contact.c
├── contact.h
├── file.c
├── file.h
└── README.md
```

## Prerequisites

- GCC compiler
- Linux or Ubuntu terminal

Install GCC on Ubuntu if required:

```bash
sudo apt update
sudo apt install build-essential
```

## Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/Neerajmaggvi/Address-Book-Using-C-Programming.git
```

### 2. Navigate to the Project Directory

```bash
cd Address-Book-Using-C-Programming
```

### 3. Compile the Program

```bash
gcc main.c contact.c file.c -o addressbook
```

### 4. Run the Application

```bash
./addressbook
```
